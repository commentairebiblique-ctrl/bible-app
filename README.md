# App Bible – Évangile éternel

 Application mobile (iOS & Android) et Web pour lire, méditer et partager la Parole de Dieu.  
Simple, moderne et accessible partout.

##  Fonctionnalités
- Lecture et méditation des Écritures
- Synchronisation sur mobile et web
- Interface claire et intuitive
- Texte fidèle et strict aux originaux, conservant le sens des Écritures

##  Installation
Clonez le dépôt et suivez les instructions pour chaque plateforme :
- iOS / Android : ouvrir dans votre IDE mobile (Xcode ou Android Studio)
- Web : lancer avec `npm install` puis `npm start`

##  Objectif
Mettre l’**Évangile éternel** à portée de tous, partout et à tout moment,  
dans une version qui respecte et conserve le sens des textes originaux.
